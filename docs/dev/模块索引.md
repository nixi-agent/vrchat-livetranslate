# 模块索引（`vlt/`）

> **派生表**：每行职责取自该文件**头部的模块 docstring 首行** —— 那才是权威源，本表只是目录。
> 改代码时同步看一眼这里；增删模块后重跑下面的命令即可核对漂移。
>
> 重生成（仓库根、任意整数 Python 均可）：
>
> ```bash
> python - <<'EOF'
> import ast, glob
> for p in sorted(glob.glob("vlt/**/*.py", recursive=True)):
>     d = ast.get_docstring(ast.parse(open(p, encoding="utf-8").read())) or ""
>     print(p, "|", " ".join(d.strip().split(chr(10))[0].split()))
> EOF
> ```
>
> 模块总数与总量（本文写作时）：**74 个模块 / 约 3.2 万行**。层与层的边界、数据流、
> 不变量见 [架构总览.md](架构总览.md)；按症状排查见 [踩坑索引.md](踩坑索引.md)。
