VRChat の中で**リアルタイム同時通訳**を行うツールです：マイク／ゲーム音声を取り込み →
Qwen Cloud のリアルタイム通訳モデルへ送信 → 訳文を **chatbox の吹き出し**と
**VR 手首オーバーレイ**に表示します。オプションで、翻訳音声を仮想サウンドカードに戻して
**相手にそのまま聞かせる**こともできます。

## 表示言語

UI は **簡体字中国語 / English / 日本語 / 한국어 / Русский** の 5 言語に対応しています。
既定では **Windows の表示言語に追従**し、**⚙ 設定**から手動で切り替えられます。
**切り替えはアプリの再起動後に反映されます。**

## できること

| 機能 | 状態 | 説明 |
|---|---|---|
| ① 自分の発話 → **chatbox の吹き出し** | ✅ 実装済み・既定でオン | マイク → エンドツーエンド音声翻訳 → 最初の差分は即送信、以降 2 秒ごとにスナップショット、文末では必ず最終版を送信 |
| ② 相手の発話 → **VR 手首オーバーレイ** | ✅ 実装済み | VRChat の再生出力（WASAPI ループバック）を取り込み → 訳文（既定は中国語）へ翻訳 → SteamVR オーバーレイに描画。**更新があれば即座に画面へ** |
| ③ 自分の発話 → **翻訳音声を相手の耳へ** | ✅ 実装済み・既定でオフ | モデルが直接出力した翻訳音声 → 48 kHz にリサンプリング → 仮想サウンドカードへ書き込み → VRChat のマイクとして拾われる。仮想サウンドカード（VoiceMeeter / VB-Cable など）はご自身で用意してください。**「マイクプロキシ」は既定で有効**：プログラムの実行中はずっと仮想サウンドカードを占有するので、VRChat 側ではそのマイクを選ぶだけで固定されます。メイン画面の `🎙 自分の声` / `🗣 翻訳の声` ボタン 1 つで、相手に届くのが自分の本当の声か翻訳音声かをワンタッチで決められます |
| ④ 自分の発話 → **タイピングで代用** | ✅ 実装済み・既定でオン | 下部の入力欄で **Enter を押すと送信**。話したくないときはキーボードで代用でき、訳文は①と**まったく同じ**経路（吹き出し／手首オーバーレイ）を通ります。「翻訳音声を出力」をオンにすると **TTS で読み上げて**仮想サウンドカードへ送るので、相手にも聞こえます |
| ⑤ 複数人 → **お互いの字幕を見る（ルーム）** | ✅ 実装済み・既定でオフ | 各自が本プログラムを起動して**同じルームコード**を入力すると、それぞれの手首オーバーレイやデスクトップ字幕に**相手の話した内容**が表示されます。ブロードキャストされるのは自分の発話のみ（ゲーム音声は転送されません）。入口：`⚙ 設定 → ルーム` |

### プラットフォーム対応

| 機能 | Windows | Linux |
|---|---|---|
| ① chatbox の吹き出し | ✅ | ✅ |
| ② VR 手首オーバーレイ | ✅ SteamVR overlay | ✅ 自作の OpenXR overlay（Monado / WiVRn） |
| ③ 翻訳音声を相手の耳へ | ✅ 仮想サウンドカード（VoiceMeeter / VB-Cable）を自前で用意 | ✅ **用意は不要**。実行時にプログラム自身が仮想マイクを宣言します |
| ④ タイピングで代用（TTS を含む） | ✅ | ✅ |
| ⑤ ルーム（お互いの字幕） | ✅ | ✅ |

      公開するプラットフォーム、長さ、スタイルも自由です。

- [ ] **② スクリーンショット付きの記事チュートリアル** — **言語不問**
      こちらも初心者向けに、「ダウンロードから最初の翻訳成功まで」の流れをスクリーンショットと文章で説明してください。
      ブログ記事、ドキュメントサイト、PDF、長いスレッド、どれでも構いません。

- [ ] **③ UI の翻訳を母語話者にチェックしてほしい** — 日本語 / 한국어 / Русский / English の母語話者の方
      UI は 5 言語に対応していますが、日本語・韓国語・ロシア語の語彙表は機械翻訳に、
